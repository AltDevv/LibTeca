
# LibTeca

LibTeca é um projeto de estudo para gerenciamento de biblioteca, desenvolvido com **Java/Spring Boot** no backend e **Dart/Flutter** no frontend.

A ideia do projeto é recriar e evoluir um sistema de biblioteca antigo, agora com uma arquitetura mais organizada, API REST, banco de dados e uma interface moderna.

## Objetivo

O principal objetivo do LibTeca é estudar na prática:

- Integração entre backend Java e frontend Flutter
- Criação de API REST com Spring Boot
- Organização de camadas no backend
- Consumo de API usando Dart/Flutter
- Modelagem de entidades e relacionamento com banco de dados
- Criação de uma interface moderna e apresentável
- Estruturação de um projeto para GitHub e portfólio

## Tecnologias

### Backend

- Java
- Spring Boot
- Spring Web
- Spring Data JPA
- H2 Database inicialmente
- Possível migração futura para PostgreSQL ou MySQL

### Frontend

- Flutter
- Dart
- Material Design
- Consumo de API REST via HTTP
